# ESERCIZIO
Un taxi applica una tariffa extra fissa dopo la mezzanotte. Scrivi una funzione che calcoli il totale della corsa dato il prezzo base, l'orario di partenza e l'orario di arrivo.


## RAGIONAMENTO
- definiamo prezzo base
- definiamo l'orario di partenza
- definiamo l'orario di arrivo
- definiamo tariffa extra = 5 euro
- Calcolo la tariffa 
- Stampo il prezzo








- definiamo il tasso di cambio
- leggiamo la somma in euro
- moltiplichiamo la somma per il tasso di cambio
- stampo il risultato
