# ESERCIZIO
Scrivi una funzione che, dato l'anno di nascita e il genere (M/F), calcoli quanti anni mancano per raggiungere l'età pensionabile (fissata a 67 anni per gli uomini e 62 per le donne).


## RAGIONAMENTO
- Definisco l'anno di nascita
- Definisci il genere (M/F)
- Fissa l'età pensionabile a 67 per gli uomini
- Fissa l'età pensiona a 62 per le donne
- Calcola gli anni che mancano alla pensione
- Stampa il risultato
